### `_FrozenList`

- actual runtime storage/type is tuple-backed;
- has no writable instance attributes (`__slots__ = ()`);
- is not a `list` subclass, so `list.__setitem__(...)` rejects it at the Python type boundary;
- exposes only a bounded `__class__ -> list` compatibility view so the already-existing Stage 2 `isinstance(value, list)` canonical JSON recognition and schema validation can read the immutable snapshot;
- preserves sequence indexing/iteration/equality needed by existing operational consumers.

### `_FrozenDict`

- actual runtime storage/type is an immutable tuple of `(key, recursively_frozen_value)` pairs;
- has no writable instance attributes;
- is not a `dict` subclass, so `dict.__setitem__(...)` rejects it at the Python type boundary;
- implements only the read-side mapping operations needed by the existing kernel (`__getitem__`, iteration over keys, `get`, `keys`, `items`, `values`, containment, equality);
- exposes the same bounded `__class__ -> dict` compatibility view for the existing Stage 2 identity/schema boundary.
