### `axm_institution/source_live_observation.py`

The Decision 023 observer now:

1. rejects non-`FilesystemObjectStore` contexts and caller-supplied `schema_dir` exactly as before;
2. captures the current bundled `*.schema.json` set into function-owned bytes plus a mutation-sensitive token;
3. writes those bytes only to a temporary invocation directory;
4. derives the Decision 022-shaped capability fact against that temporary interpretation context;
5. for supported kinds, temporarily directs the exact `store.load_bytes(target_object_ref)` validation path to the same temporary interpretation context;
6. restores the store's prior `schema_dir` in `finally`;
7. fails closed if the ambient bundled schema set changed during the invocation or if the store interpretation override drifted;
8. otherwise emits the same bounded Decision 023 result classes as before.

The temporary interpretation copy is destroyed when the invocation exits. It is not named as historical context identity, is not retained as institutional evidence, and does not change `context_standing = live_mutable_store` or `reexecution_standing = not_established`.

The coherence guarantee therefore comes from the interpretation actually used by both phases, not merely from comparing mutable schema bytes before and after. The ambient mutation check is an additional fail-closed guard and catches the unchanged ADV-058-A swap/restore path.
