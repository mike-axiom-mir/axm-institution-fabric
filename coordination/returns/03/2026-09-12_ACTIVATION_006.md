- Stage 1 schemas permit general continuation-relevant strings, including artifact `type`, `content_ref`, provenance `source_refs`, and free-form `notes`.

Concrete byte-level counterexample:

```text
logical string value: a/b

current production rendering:
"a/b"

alternate JSON spelling for the same string value:
"a\/b"
```

Both spellings decode to the same string value. The current Python implementation chooses the first because of `json.dumps` behavior, but a fresh implementation reading repository contract text is not explicitly told that optional solidus escaping is forbidden. Therefore canonical bytes can still depend on serializer ancestry for this supported value.

Targeted witness executed during this activation:

Status: **observed contract/implementation portability ambiguity**. This is not a claim that the Python implementation is internally nondeterministic; it is a reconstructability failure for a replacement implementation.
