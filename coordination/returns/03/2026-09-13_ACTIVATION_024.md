## Exact scenario / counterexample

### ADV-036 — builtin base-class mutator bypass

Lane 02's ADV-035 repair recursively freezes exact-loaded operational JSON into private subclasses of Python `dict` and `list` and overrides their ordinary mutating methods to raise `TypeError`.

That blocks ordinary calls such as:

- `value.__setitem__(...)`;
- `value["field"] = ...`;
- nested frozen-list ordinary mutation.

However, because the returned objects are still actual `dict` / `list` subclasses, Python permits direct invocation of the builtin base-class mutators:

- `dict.__setitem__(frozen_dict, key, value)`;
- `list.__setitem__(frozen_list, index, value)`.

Those calls bypass the subclass override and mutate the supposedly exact operational value after its immutable reference has already been verified.

Three deterministic witnesses were added:

- **ADV-036-A:** use `dict.__setitem__` to change a resolved created artifact's `type` while retaining the original exact artifact ref;
