
#### `axmref:v1` components

Canonical component spelling is now specified byte-for-byte:

- canonical input text -> UTF-8 bytes;
- raw ASCII: `A-Z a-z 0-9 - . _ ~`;
- every other byte -> uppercase `%HH`;
- spaces -> `%20`, never `+`;
- literal `%` -> `%25`;
- non-ASCII -> UTF-8 bytes percent-encoded;
- parsing rejects spellings that do not round-trip to the exact canonical encoding.

Required regression:

```text
a!b*a'b(c)
-> a%21b%2Aa%27b%28c%29
```
